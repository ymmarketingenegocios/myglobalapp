Google Sheets

◫ Conexão

Cole a URL gerada pelo Apps Script. Todos os dados serão sincronizados automaticamente.

Status da conexão
Configure a URL acima para ativar a integração.
Passo a passo
  1. Crie uma planilha em sheets.google.com com o nome YM Command Center
  2. Acesse Extensões → Apps Script e cole o conteúdo de ym-apps-script.gs
  3. Salve, selecione a função setupPlanilha e clique em Executar (autorize)
  4. Vá em Implantar → Nova implantação → App da Web
  5. Executar como: Eu mesmo · Acesso: Qualquer pessoa
  6. Copie a URL gerada e cole acima → Salvar URL
  7. Clique em Testar conexão → deve aparecer ✓
  8. Clique em Sincronizar agora para enviar todos os dados
