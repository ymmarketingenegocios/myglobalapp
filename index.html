Conexão Google Sheets

◫ URL da planilha

Cole a URL do Apps Script (Web App) para sincronizar com Google Sheets. Os dados também ficam salvos localmente no navegador automaticamente.

Como configurar
  1. Crie uma planilha Google Sheets com as 12 abas
  2. Abra o editor de scripts: Extensões → Apps Script
  3. Cole o código do Apps Script fornecido
  4. Clique em Implantar → Nova implantação → App da Web
  5. Defina acesso: "Qualquer pessoa"
  6. Copie a URL gerada e cole acima

IMPORTANTE

Sem a URL configurada, todos os dados são salvos localmente no seu navegador (localStorage). Configure o Sheets para backup permanente e acesso em múltiplos dispositivos.
