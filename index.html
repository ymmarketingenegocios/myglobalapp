⚙ Geral

Google Sheets

◫ Conexão

Cole a URL gerada pelo Apps Script. Todos os dados serão sincronizados automaticamente.

Status da conexão
Configure a URL acima para ativar a integração.
Passo a passo
  1. Crie uma planilha em sheets.google.com com o nome YM Command Center
  2. Acesse Extensões → Apps Script e cole o conteúdo de ym-apps-script.gs
  3. Salve, selecione a função setupPlanilha e clique em Executar (autorize)
  4. Vá em Implantar → Nova implantação → App da Web
  5. Executar como: Eu mesmo · Acesso: Qualquer pessoa
  6. Copie a URL gerada e cole acima → Salvar URL
  7. Clique em Testar conexão → deve aparecer ✓
  8. Clique em Sincronizar agora para enviar todos os dados

Importar dados

↑ Importar CSV

Selecione o módulo de destino e envie o arquivo CSV. Cabeçalhos detectados automaticamente — não precisa organizar manualmente.

📂
Clique ou arraste o arquivo aqui
Aceita .csv exportado do Excel, Google Sheets ou qualquer planilha
Templates de importação

Baixe o template de cada módulo para ver as colunas esperadas.

Como funciona
  • Cabeçalhos detectados automaticamente — maiúsculo, minúsculo, acentos, espaços: tudo funciona
  • Colunas desconhecidas são ignoradas silenciosamente
  • IDs duplicados são ignorados — importação segura e idempotente
  • Campos obrigatórios ausentes geram aviso no relatório de importação
  • Valor líquido calculado automaticamente no módulo Financeiro
  • Após importar, dados sincronizam com Google Sheets automaticamente
